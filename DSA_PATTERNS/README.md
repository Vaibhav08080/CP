# DSA PATTERNS - COMPLETE LEARNING GUIDE

## Welcome to Pattern-Based DSA Learning! 🚀

This is a **pattern recognition** approach to learning DSA. Instead of learning algorithms in isolation, you learn to **recognize patterns** in problem statements and apply **memorized templates**.

---

## LEARNING METHODOLOGY

### How to Use This Resource

1. **Read Pattern Recognition Section** - Learn the "red flags" that signal a pattern
2. **Study Templates** - Memorize 2-3 reusable code templates per pattern
3. **Solve Problems** - Practice the listed problems using the templates
4. **Analyze Examples** - Study full working examples with complexity analysis
5. **Practice & Repeat** - Solve more problems until pattern is automatic

### Why This Works

✓ Pattern recognition automates problem-solving strategy selection
✓ Templates eliminate coding from scratch
✓ Repeated practice builds muscle memory
✓ Real examples show variations
✓ Complexity analysis shows efficiency

## HOW TO SOLVE A NEW PROBLEM

1. **Read problem carefully** - Identify keywords
2. **Match to pattern** - Look for red flags
3. **Apply template** - Use the memorized template
4. **Adapt to specifics** - Modify for problem details
5. **Code & test** - Write working code
6. **Analyze complexity** - Time and space

### Example: "Find Two Numbers in Array that Sum to Target"

```
Step 1: Keywords - "two", "sum", "array"
Step 2: Pattern - Hash Map (find pair)
Step 3: Template - Seen dictionary approach
Step 4: Code:
    seen = {}
    for num in nums:
        complement = target - num
        if complement in seen:
            return [seen[complement], num]
        seen[num] = index
Step 5: Complexity - O(n) time, O(n) space
```

## QUICK REFERENCE: WHEN TO USE EACH PATTERN

| Pattern | Use When | Red Flag Keywords |
|---------|----------|------------------|
| Array | Basic operations | Find, count, iterate |
| Sliding Window | Subarray with size/condition | Longest, shortest, contains |

| Fast/Slow | Cycle/middle in linked list | Cycle, middle, kth |
| Binary Search | Sorted data | Search, log n, position |
| Prefix Sum | Range queries | Sum between, query |
| Hash Map | Frequency/pairing | Duplicate, frequency, pair |
| Stack | LIFO/validation | Parentheses, next, LIFO |
| DFS | All solutions/paths | All, permutation, explore |
| BFS | Shortest path/level | Shortest, level, minimum |
| Tree | Tree traversal | Inorder, path, height |
| Graph | Shortest path/connectivity | Path, connected, distance |
| DP | Overlapping subproblems | Min/max, optimize, ways |
| Greedy | Local optimal | Maximize, minimize, select |
| Heap | Top K/priority | Top, median, frequent |
| Matrix | 2D grid | Grid, 2D, boundaries |
